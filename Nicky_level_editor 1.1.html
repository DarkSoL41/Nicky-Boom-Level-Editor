Load at least DECORn.CDG and DECORn.BLK for one level (the "Pick files" button, you can select several at once), or use "Open game folder" above. REF is optional. The colour palette is always approximated (the level-1 built-in palette), since the original game doesn't ship a separate palette file.

Drawing: left click places the selected tile, the eyedropper picks a tile from the map. Export rebuilds the .CDG in sqx format; the "No compression" checkbox is on by default — it's the only mode confirmed to load in the real DOS game (the file will be bigger, but that's not a problem).

To edit monsters/items, also load POSITn.REF and REFn.REF (optionally the sprite files S0n.SPR/S1n.SPR for picture previews), then switch to the "Objects" tab on the left.

Important about objects: moving, editing and deleting existing objects is safe (the editor re-sorts them by X on export — the engine needs that to display them correctly). Adding new objects beyond the original count will most likely corrupt memory in the game (e.g. level 1's buffer is already 100% full: 409 of 409) — the editor will warn you before export if the object count has increased.

Editor made by DarkSoL (Discord: darksol41), based on the source code of Gregory Montoir's engine reimplementation — cyx (nicky-0.2.0-src) and with the help of the Claude AI (Anthropic).
sqx — Nicky Boum (Microids, 1992) compression format, algorithm recovered from the same source code. Map layout is column-major (col*H+row), 400×50 tiles of 16×16px, 4bpp planar.
